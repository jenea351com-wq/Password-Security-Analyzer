# Password Security Analyzer (v1.0)

Инструмент на Python для анализа криптостойкости паролей с современным графическим интерфейсом.

## 🚀 Основные возможности
* **Визуальная шкала надежности:** Динамический Progress Bar, который заполняется в зависимости от сложности пароля.
* **Глубокий анализ:** Проверка длины, наличия заглавных и строчных букв, цифр и спецсимволов.
* **Защита от утечек:** Автоматическая сверка с базой данных (Blacklist) самых популярных и небезопасных паролей.
* **Безопасный ввод:** Использование маскировки вводимых данных (символы скрыты при наборе).

## 🛠 Технологии
* **Язык:** Python 3.x
* **Библиотеки:** * `tkinter` — создание основного окна и виджетов.
  * `ttk` — использование современных элементов интерфейса (Progressbar).

## ⚙️ Как запустить
1. Установите Python с сайта python.org.
2. Скачайте файл `gui_start.py`.
3. Запустите его командой: `python gui_start.py`
